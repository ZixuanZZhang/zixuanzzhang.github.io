# zixuanzzhang.github.io

Personal homepage of Zixuan Zhang, served by GitHub Pages at https://zixuanzzhang.github.io/.

- `index.html` – the whole site: markup, styles and the four live research figures (plain HTML/CSS/JS, no build step).
- `assets/` – portrait, talk slides, favicon and the social share card (`og.png`).
- `.nojekyll` – tells GitHub Pages to serve the files as-is.

The previous Jekyll (academicpages) site is preserved on the `academicpages-archive` branch.
